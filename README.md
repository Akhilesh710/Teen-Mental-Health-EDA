# 🧠 Teen Mental Health EDA

An Exploratory Data Analysis (EDA) project focused on understanding factors affecting teen mental health using Python data analysis and visualization libraries.

---

# 📌 Project Overview

This project analyzes a teen mental health dataset containing information related to:

* Social media usage
* Sleep habits
* Academic performance
* Stress & anxiety levels
* Lifestyle patterns
* Depression indicators

The main goal of this project is to identify patterns, trends, and relationships that may contribute to teen depression.

---

# 🎯 Objectives

* Perform complete Exploratory Data Analysis (EDA)
* Clean and preprocess the dataset
* Analyze distributions of features
* Find correlations between variables
* Identify factors linked with depression
* Generate visual insights for better understanding

---
